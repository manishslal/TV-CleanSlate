# Device logs

Each folder records what was changed on one tested device, how to undo it, and what was verified. `restore-cleanup.sh`, where present, re-enables packages for that device. `devices.json` is the machine-readable list.

Package lists and disable lists apply only to that model and firmware. Don't copy them to a different device.

IP addresses, MAC addresses, Wi-Fi names and locations are replaced with placeholders.
