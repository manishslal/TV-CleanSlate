# Device logs

Each folder records what was changed on one tested device, how to undo it, and what was verified. `restore-cleanup.sh`, where present, re-enables packages for that device. `devices.json` is the machine-readable list.

These are records of what one owner chose for their own TV, not instructions. Some choices, such as rooting the LG or blocking its updates, trade away support or security fixes; decide those for yourself. Disable lists apply only to that model and firmware. Don't copy them to a different device. Full installed-app lists are left out for privacy.

IP addresses, MAC addresses, Wi-Fi names, device names and locations are replaced with placeholders.
