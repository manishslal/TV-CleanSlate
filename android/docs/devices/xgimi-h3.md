# 极米 H3（国行）

- 用户实测，2026-10-26。固件版本和 Android 版本这次没有单独记录。
- 未 root、未刷机。

## 开 ADB：系统里没有入口

这台机器的设置里没有可用的开发者选项。ADB 没打开时，`adb connect <IP>:5555` 返回 `Connection refused`。

可行的做法与 [Z7X](xgimi-z7x.md) 相同：用 U 盘安装 [code-ant/z7x-adb](https://github.com/code-ant/z7x-adb)（极米 ADB 开启器）并打开一次。该工具原先只在 Z7X 上验证过；这次在 H3 上同样能打开网络 ADB，随后可以正常安装应用。普通应用权限即可，不需要 root，也不进工厂模式。

第三方工具自行评估风险。Aerial 本身不依赖它，它只是这台机器打开 ADB 的入口。工具作者也写了不保证全部极米型号，这里只记录 H3 这一台的结果。

## 安装与使用

ADB 打开之后，按仓库的正常流程安装即可。这次实测 `adb install` 成功，Aerial 可以正常使用。

开机后是否自动回到 Aerial、屏保接管、长按 Home 的行为，这次没有单独测量，不要沿用 Z7X 笔记里的那些结论。
